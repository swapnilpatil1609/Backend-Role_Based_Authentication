
# Role-Based Music Player Backend

A music player backend built using Node.js, Express.js, and MongoDB.

## Features
- User registration and login using JWT
- Role-based authentication for users and artists
- Music uploads using Multer and Cloudinary
- Album creation and music management
- MongoDB database integration

## Tech Stack
- Node.js
- Express.js
- MongoDB and Mongoose
- JWT
- bcrypt
- Multer
- Cloudinary

## Setup
1. Clone the repository.
2. Run `npm install`.
3. Create a `.env` file with the required environment variables.
4. Run `npm start` (or your configured development command).
